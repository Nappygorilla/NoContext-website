Developer Platform

luna.win API

Build integrations with luna.win using versioned endpoints, developer API keys, and predictable JSON responses.

Base URL

https://nocontext.onrender.com/api/v1

Send your API key in the X-luna.win-API-Key header. Never expose a developer key in browser-side code or public repositories.

Endpoints

GET /api/v1

Returns API metadata and available public endpoints.

GET /api/v1/me

Returns the luna.win account associated with the API key.

GET /api/v1/keys

Lists the developer API keys belonging to the authenticated account. Secrets are never returned.

POST /api/v1/licenses/validate

Validates a luna.win product license.

curl -X POST https://nocontext.onrender.com/api/v1/licenses/validate \ -H "Content-Type: application/json" \ -H "X-luna.win-API-Key: nc_dev_YOUR_KEY" \ -d '{"key":"NC-XXXX-XXXX-XXXX-XXXX","product":"luna.win External"}'

Authentication

Create and manage your developer API keys from your signed-in luna.win account. The raw key is shown only when it is created, while the server stores only a hash.

Public API access is separate from owner/admin credentials and the Discord bot secret.
